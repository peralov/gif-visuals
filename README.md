# Gif Visuals

A demo of this project is available on https://peralov.github.io/gif-visuals

## Project Setup and Development

This project consists of a Node.js backend server and client-side applications: a main application and a mobile controller. The client-side is served using Vite for development.

### Prerequisites

*   Node.js (version 18 or higher recommended)
*   npm (comes with Node.js)

### Installation

1.  **Navigate to the project directory**:
    ```bash
    cd gif-visuals
    ```
2.  **Install Node.js dependencies**:
    ```bash
    npm install
    ```

### Running the Project

To run the project, you need to start both the Node.js backend server and the Vite development server for the client applications.

1.  **Start the Node.js Backend Server**

    Open a new terminal window, navigate to the `gif-visuals` directory, and run:
    ```bash
    npm start
    ```
    This will start the Express and Socket.IO server, typically on `http://localhost:3000`.

2.  **Start the Vite Development Server**

    Open *another* new terminal window, navigate to the `gif-visuals` directory, and run:
    ```bash
    npm run dev:client
    ```
    This will start the Vite development server, usually on `http://localhost:5173`. Vite will serve the `index.html` from the `public` directory and proxy `/socket.io` requests to your Node.js backend.

### Accessing the Applications

*   **Main Application**: Once the Vite development server is running, open your browser to the address provided by Vite (e.g., `http://localhost:5173`).
*   **Mobile Controller**: The mobile controller application is located within the `public/mobile/` directory. You can access it in your browser at `http://localhost:5173/mobile/mobile.html`.

### Project Structure Overview

*   `gif-visuals/public/`: Contains the client-side assets (HTML, CSS, JavaScript, images) for both the main and mobile applications.
    *   `index.html`: The main entry point for the primary client application.
    *   `client/`: Client-side JavaScript files for the main application.
    *   `css/`: Client-side CSS files for the main application.
    *   `img/`: Image assets.
    *   `mobile/`: Contains the mobile controller application.
        *   `mobile.html`: The main entry point for the mobile controller.
        *   `mobileController.js`: JavaScript logic for the mobile controller.
        *   `sms.html`: Another HTML file related to the mobile functionality.
        *   `style.css`: CSS for the mobile controller.
*   `gif-visuals/index.js`: The main Node.js server file, handling static file serving (in production) and Socket.IO connections.
*   `gif-visuals/gifsApi.js`: Contains logic for interacting with a GIF API.
*   `gif-visuals/package.json`: Project metadata and script definitions.
*   `gif-visuals/vite.config.js`: Configuration for the Vite development server.

### Keyboard Shortcuts (Main Application)

These shortcuts are active when the main application is in focus:

*   **Number keys (1-9)**: Change the grid layout (e.g., `1` for a 1x1 grid, `2` for 2x2, etc.).
*   **`q`**: Apply "PARTY" effect (`colorEffect`).
*   **`w`**: Apply "MEME" effect (`swipeEffect`).
*   **`e`**: Apply "FLIP" effect (`flipEffect`).
*   **`r`**: Apply "FLASH" effect (`invertEffect`).
*   **`t`**: Apply "FEEL" effect (`shakeEffect`).
*   **`s`**: Toggle visibility of the header containing the word.

### Mobile Client Controls

Access the mobile client at `http://localhost:5173/mobile/mobile.html`.

*   **Image Category Clicks**: Clicking on the image categories displayed on the mobile client will update the GIFs shown in the main application.
*   **Word Input and Enter Key**: Type a word into the input field and press "Enter" to change the word displayed on the main application's header.

### Important Notes

*   During development, the Vite server (`npm run dev:client`) serves the client-side files and proxies API requests to the Node.js server (`npm start`).
*   In a production environment, your `index.js` server would typically serve the static client assets generated by a Vite build. You can run `npm run build` (after adding a build script) to create a production-ready client bundle in the `dist` directory.
